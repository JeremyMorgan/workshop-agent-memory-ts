Memory makes an agent more capable and more dangerous. An agent that remembers can act on what it remembers, and it can be taught things that are not true.

In this module, you move two safety rules out of the prompt and into code, then watch a planted memory get stored and trusted until provenance and a trust filter stop it.

By the end of this module, you will be able to:

- Explain why a prompt is not a security boundary
- Enforce an approval gate and a recipient allowlist inside tool execution
- Describe how memory poisoning works and how provenance limits it
- Stamp each stored fact with a source and a trust level, resolved by code
