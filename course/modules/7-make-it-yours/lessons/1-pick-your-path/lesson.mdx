<Slide title="Three paths">

<Column slideOnly>

Pick one. Each takes about 18 minutes and ends with something you can check.

* **Path 1, dry-run:** Run with `mode: "dry-run"`. Writes are logged and reported as success, and nothing changes. Then implement one tool in `src/workshop/nsuite/real.ts` against an API you own, and prove it through the audit log.
* **Path 2, your own tool or stage:** Add a tool to `customTools` in `src/agent.ts`, or write a tool as a spec so it is audited and mode-switched for free. Teach `mapToolResult` about its output so the results land in the graph.
* **Path 3, your own rule:** Keep the tools, change the policy. Add a guard, a pinned rule, or a trust rule for something you care about, and make the agent hit it.

</Column>
