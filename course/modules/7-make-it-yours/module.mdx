You have built a context pipeline: input processors, step hooks, tool guards, and memory policies. Together they decide what the model sees and what it can do.

In this module, you pick one way to make that pipeline your own, build it, and show it to the room. The module ends with the managed form of the memory you built, and where to go next.

By the end of this module, you will be able to:

- Choose which part of the pipeline to change for a purpose of your own
- Add a tool, a stage, or a rule and check it against the graph
- Explain what you changed and what it makes the agent remember
- Describe NAMS, the managed memory service, and when to use it
