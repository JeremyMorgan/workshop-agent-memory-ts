<Column slideOnly>

Mastra has its own semantic recall, which searches past messages in a thread. This workshop does not use it.

The question here is about emails, events, and tickets, not about earlier messages, so the baseline is a small custom index in `src/workshop/retrieval/semanticIndex.ts`.

It embeds one chunk per email, event, and ticket locally with `@mastra/fastembed`, so no API key is needed, and ranks them by cosine similarity. No tricks: plain chunks, plain top-k.

The `topK` of 4 is Mastra's own default for semantic recall, so the baseline is not tuned to lose.

</Column>

<Column slideOnly>


<Slide title="Switch it on">

<Column slideOnly>

`SemanticContext` is an input processor. Once per user turn, it searches the index with the user's question and adds the top 4 hits as a system message. It records the retrieved items and their scores, so they appear in the trace.

Set `retrieval` to `semantic` and restart.

</Column>
