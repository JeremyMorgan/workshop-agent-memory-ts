Retrieval decides what goes into the context for this question. Memory that is stored but not retrieved is not memory.

In this module, you compare two ways of retrieving. The first is a flat semantic search, which finds text that sounds like the question. The second walks the graph, which finds what is connected to the question. You run both on a question where only one of them can find the answer.

By the end of this module, you will be able to:

- Explain why similarity search can return related text that is not useful
- Load the same data into a vector index and a graph
- Write a graph retrieval step that follows relationships from the entities in a question
- Compare semantic, graph, and combined retrieval on the same question
