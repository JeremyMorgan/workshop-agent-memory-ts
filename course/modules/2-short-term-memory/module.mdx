Short-term memory is the conversation itself: the messages between a user and an agent, stored as they happen and read back on the next turn.

In this module, you first watch a small history window push a rule out of the context while the agent is still working, and then switch on Mastra message history and size that window yourself.

By the end of this module, you will be able to:

- Show that a rule stated early leaves the context, and the agent then acts as if it never existed
- Turn on message history and set the size of the window with `history` and `historyWindow`
- Explain why one turn takes more than two messages once tools are involved
