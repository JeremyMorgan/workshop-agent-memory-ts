An agent is a loop: the model reads its context, asks for a tool, reads the result, and goes round again. The context is the only thing the model knows, so the quality of the agent is the quality of what you put in it.

In this module, you meet the workshop agent, set up your environment, and break the agent on purpose so you have a failure to fix.

By the end of this module, you will be able to:

- Describe the agent loop and the four places you can shape its context
- Name the three layers of memory and how they fit into one graph
- Run the workshop agent against a local Neo4j instance
- Show that an agent with no memory deletes what it should not
