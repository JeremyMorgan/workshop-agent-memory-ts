## Workshop complete

You took an agent that forgets and gave it memory you can inspect, trace, and trust.

You have learned:

- That the model only knows what is in its context window, and that you decide what goes in
- How short-term memory with a history window loses a rule, and how a context trace in Neo4j shows exactly when
- How long-term memory and pinned rules keep facts and rules across sessions
- How graph retrieval follows a relationship that semantic similarity cannot
- How guards in code, provenance, and a trust filter keep an agent safe when its memory is not
