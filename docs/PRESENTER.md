# Presenter guide

The facilitator guide lives with the course content: `course/instructor.mdx`. It has the timing table, the run command and replay fallback for each module, the catch-up table (`npm run step -- N`), the story cues with their sources, and the close.

Quick reference:

- Replay any demo with no model or Neo4j: `npm run scenario -- N --replay`
- Restore everything between demos: `npm run reset`
- Ground truth for what the agent did: `npm run state`
- Jump a learner to a stage: `npm run step -- N`
